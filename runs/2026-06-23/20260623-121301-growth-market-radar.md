# GitHub 需求模式提炼与服务方向映射

**任务核心：** 基于今日 GitHub 公开项目雷达（30个项目），提炼 **30 个可复制/学习的通用需求模式**，并将每个模式映射到 **2-3 个可立即测试的新服务方向**，避免仅依赖现有 P01/P02/P03 路径。

**核心发现（模式归类）：** 今日项目高度集中在 **AI 代理（Agent）、自动化工作流（n8n）、线索生成与数据清洗、垂直行业AI套件** 四大领域。这表明市场对 **“自动化执行”和“AI辅助决策”** 的交付需求依然强劲，且正在向更细分的场景（如特定行业、特定工具链）渗透。
