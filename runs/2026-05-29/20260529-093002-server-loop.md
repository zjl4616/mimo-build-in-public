**核心功能**：
1.  用户粘贴一段 n8n 工作流 JSON。
2.  点击按钮。
3.  页面清晰地用中文逐项解释：工作流概述、每个节点（Node）的类型与关键参数、主要数据流向、潜在配置风险点。

**交付格式**：单个 HTML 文件，包含所有 CSS 和 JavaScript，无需后端，可直接通过浏览器打开使用，或托管在 GitHub Pages 上。
