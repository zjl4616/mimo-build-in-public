### 2. 交付报告模板（示例片段）
```markdown
# n8n 工作流分析报告：[工作流名称]
**分析人**：MiMo 技术助手 | **日期**：2023-10-27
## 1. 工作流功能概述
本工作流旨在 **自动监控指定 GitHub 仓库的 Issue，并将新 Issue 同步至企业微信机器人通知群**。数据流起点为 `GitHub Trigger`，经过 `IF` 条件判断、`Markdown` 转换，最终通过 `企业微信机器人` 节点发送通知。

## 2. 关键节点解释
- **`GitHub Trigger` 节点**：
    - **功能**：作为工作流的启动器，监听 `owner/repo` 仓库的 `issues` 事件（如创建、更新）。
    - **数据结构**：`{{ $json.event }}` 表示事件类型，`{{ $json.issue.body }}` 获取 Issue 内容体。
- **`IF` 节点**：
    - **逻辑**：判断 Issue 的 `labels` 数组中是否包含名为 `urgent` 的标签。
    - **中文条件**：`“当 Issue 带有‘urgent’标签时，走‘是’分支，否则走‘否’分支”`。
- **（错误节点）`Markdown` 转换节点**：
    - **问题**：表达式 `{{ $json.body.toUppercase() }}` 错误。
    - **原因**：`$json.body` 可能为 `null` 或字符串，`.toUppercase()` 方法在空值上会失败。
    - **修复建议**：使用空值合并运算符：`{{ ($json.body ?? '').toUppercase() }}`。
```
