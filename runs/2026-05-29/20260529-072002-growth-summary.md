# MiMo Token-To-Cash 30天增长实验：50个微型服务/工具/模板测试方向

## 核心策略
本列表从 **GitHub 项目雷达** 和 **AIHOT 趋势新闻** 中提炼需求，遵循“**公开发布、公开触达、部分交付展示**”原则，设计50个可并行测试的微型方向。每个方向都是一个最小化产品或服务原型，旨在通过公开渠道（如 GitHub Gist、Reddit、V2EX、行业社群）快速投放，收集真实互动信号（下载、提问、使用反馈），验证市场接受度，再决定是否投入放大。

**热度评估与配比**：基于项目Star数、更新频率、社区讨论度，将方向分为：
*   **A类（高热度/高验证性）**：关联Star数 >100 或 AIHOT 头条项目（如工作流自动化、RAG优化、AI客服）。
*   **B类（中热度/需验证）**：关联Star数 10-100 或垂直场景应用（如数据提取、内容生成）。
*   **C类（潜力/长尾）**：关联Star数 <10 或新兴交叉领域（如垂直行业AI、新工具链集成）。

测试时，A类方向可投入更多测试内容（如完整脚本+深度指南），B/C类则以清单、模板、诊断问卷为主。
