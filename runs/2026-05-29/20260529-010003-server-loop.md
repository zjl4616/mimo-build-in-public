## 可直接保存/复制的内容

### **内容1：工具仓库 `README.md`**
```markdown
# n8n JSON 中文解释器 (n8n-json-explainer)

将复杂的 n8n 工作流 JSON 转换为清晰、可读的中文流程图和步骤说明。

## ✨ 功能特性
- **流程可视化**：自动生成节点连接关系的流程图 (Mermaid 语法)。
- **步骤中文详解**：将每个节点配置转换为结构化中文描述。
- **敏感信息提示**：自动识别并高亮可能的敏感数据（如 `password`, `apiKey`）。
- **离线使用**：无需联网，完全在本地运行。

## 🚀 快速开始
```bash
# 1. 克隆仓库
git clone https://github.com/your-repo/n8n-json-explainer.git
cd n8n-json-explainer

# 2. 安装依赖 (推荐 Python 3.8+)
pip install -r requirements.txt

# 3. 运行解释器
python explain.py --input your_workflow.json --output explained.md
```

## 📖 示例
**输入 JSON 片段** (一个简单的 HTTP Request 节点):
```json
{
  "parameters": {
    "method": "POST",
    "url": "https://api.example.com/data",
    "sendBody": true
  },
  "type": "n8n-nodes-base.httpRequest",
  "name": "发送数据"
}
```

**输出中文解释**:
```
节点 3: 发送数据 (类型: HTTP Request)
- 操作: 发送 POST 请求
- 目标 URL: https://api.example.com/data
- 携带请求体: 是
```
