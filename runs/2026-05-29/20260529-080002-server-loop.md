# n8n 工作流 JSON 脱敏工具 - 使用指南

**解决痛点**：你需要在社区求助或分享n8n工作流时，避免暴露API密钥、令牌和敏感URL。

## 🛠 工具功能
本工具是一个离线、纯静态的浏览器端脚本。它能：
1.  **智能识别**：自动检测JSON工作流中所有可能的凭证（Credentials）和敏感变量。
2.  **安全替换**：将识别出的敏感值替换为无害的占位符（如 `YOUR_API_KEY`）。
3.  **生成报告**：输出脱敏后的JSON，并附带一份简报，列出所有被替换的字段和位置，方便你在分享后知道何处需要恢复。

4.  从右侧复制脱敏后的安全JSON，即可公开分享。
5.  **重要**：查看下方“脱敏报告”，记住你需要恢复原值的字段。
