# MiMo Build in Public

[中文](./README.md) | English

This repository documents the **MiMo Token-To-Cash** experiment in public: using AI agents, GitHub, Feishu communities, WeChat articles, AI trend feeds, and lightweight public launches to turn ideas into testable products.

> Principles: no fake revenue, no fake customers, no exaggerated claims, no automatic payment handling. Only verifiable links, artifacts, experiments, and retrospectives are published.

## Current Strategy

1. **All-day loop**: trend mining, product generation, public launch, and feedback tracking run throughout the day.
2. **Batch testing**: do not bet on one idea; publish 30/100+ lightweight tests and let real feedback decide.
3. **Sell shovels**: diagnostics, templates, automation tools, prompt packs, and workflows.
4. **Go vertical**: AI customer support, foreign-trade inquiries, B2B websites, AI image gigs, code security, agent architecture, etc.
5. **Scale by evidence**: clicks, GitHub issues, DMs, sample submissions, and paid requests decide what to amplify.
