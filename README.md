# MiMo Build in Public / MiMo 公开赚钱实验

中文 | [English](./README.en.md)

这是一个公开记录 **MiMo Token-To-Cash** 的实验仓库：用 AI Agent、GitHub、飞书社群、公众号文章、AI 趋势新闻和公开发布，把想法快速变成可测试产品，并持续记录哪些方向有反馈、哪些应该停止。

> 原则：不伪造成交，不夸大收益，不自动收款；只公开可验证的链接、产物、实验和复盘。

## 当前策略

1. **全天运行**：趋势学习、产品生成、公开发布、反馈记录全天进行。
2. **批量测试**：不押注单个产品，先快速发布 30/100+ 个轻量测试入口。
3. **卖铲子**：优先做诊断、模板、自动化工具、提示词包、工作流，而不是自己下场挖金。
4. **做垂类**：AI客服、外贸询盘、B2B独立站、AI图片接单、代码安全、Agent架构等。
5. **结果驱动**：以真实点击、Issue、私聊、样本提交、付款为放大依据。
